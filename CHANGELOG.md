## [1.1.0] - 2026-11-11

### Added

- English is now the default application language.
- Language selection is available in the first-run dialog and main toolbar,
  persisted in `%APPDATA%\fan_studio\settings.ini`.
- English translations for the editor, motor library, inspector, timeline,
  dialogs, user guide, terms, and privacy policy.
- English official website at `/`; Simplified Chinese remains at `/zh/`.
- English `README.md` with the complete Chinese README preserved as
  `README.zh.md`.
- English and Chinese changelogs.

### Changed

- Public API reports version `1.1.0`.
- Website and API navigation expose both language entries.
