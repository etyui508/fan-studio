# fan_studio 使用说明

版本 1.1 · 2026-11-10

`fan_studio.exe` 是 fan_music 的桌面电机乐器编辑器。它直接使用 C# 物理引擎，`.fscore` 是工程文件，WAV 是仿真预览。首次启动会显示用户协议和隐私政策；同意记录只写在本机。

## 1. 打开与保存

1. 双击 `fan_studio.exe`。
2. 使用“打开 .fscore”载入现有工程，或直接开始“未命名项目”。
3. 使用“保存”写回工程。没有路径时会打开另存为窗口。
4. 右上角 `?` 可随时重新查看本说明、用户协议和隐私政策。

## 2. 界面

### 电机库

- 按型号、族系或角色搜索。
- 同一台电机在电机库、卷帘音域带和音符上使用同一种颜色。
- 双击电机卡片会在播放头位置添加一台电机。
- 把卡片拖进卷帘，会在落点音高和时间创建声部与音符。

### 钢琴卷帘

- 横轴：节拍。纵轴：音高。
- 双击空白处：在选中声部创建音符。
- 拖动音符：修改拍位和音高。
- 拖动音符右边缘：修改时值。
- 空白处拖拽：框选。
- 红色边框：音域越界，或音符短于电机的 3.5τ 整定时间。

### 检查器

- 修改音高、起始拍、长度。
- 修改叶片数、谐波、转速上下限、启动占空比、惯性、音色、噪声、声像、音量和摆位延迟。
- “试听声部”只播放当前声部。
- “删除声部”可以用 `Ctrl+Z` 撤销。

### 底部诊断

- 柱状图显示当前可见时间范围内同时发声的电机数量。
- 红色虚线为 8 台参考线。超过该线时低频更容易互相遮蔽。
- 右下角汇总时值与音域风险。
- “适应内容”会同时调整时间范围和音高范围。

## 3. 音高尺

音高尺使用深色文字标签，不画白色钢琴键。

- 缩小时只显示 C 行。
- 放大后显示更多音名。
- 黑键所在行颜色稍深，C 行有更亮的八度分界。
- 当前声部音域内的音名使用该电机颜色，范围外变暗。
- 悬停某一行会显示：音名、频率、当前声部达到该音高所需的 RPM。
- 点击左侧音名立即试听。超出当前电机音域时只显示提示，不会播放。

## 4. 视图操作

| 操作 | 效果 |
|---|---|
| 滚轮 | 上下滚动 |
| `Shift + 滚轮` | 左右滚动 |
| `Ctrl + 滚轮` | 同时缩放时间与音高行高 |
| 点击“适应内容” | 调整到当前项目音符所在范围 |
| 选中其他电机 | 音域不在画面内时自动滚动到其范围 |

| 快捷键 | 功能 |

| `Space` | 播放/停止 |
| `Ctrl+S` | 保存 |
| `Ctrl+Shift+S` | 另存为 |
| `Ctrl+O` | 打开 |
| `Ctrl+N` | 新建项目 |

| `Ctrl+Z` / `Ctrl+Y` | 撤销/重做 |
| `Ctrl+A` | 全选音符 |
| `Ctrl+D` | 复制选中音符 |
| `Delete` | 删除选中音符 |
| 方向键 | 音高上下、拍位左右微调 |
| `Shift + 左右键` | 修改选中音符长度 |
| `Ctrl + 上下键` | 整体移动一个八度 |

## 6. MIDI 导入

1. 点击“导入 MIDI”。
2. 选择声部数、最长时长和工程 BPM。
3. 软件调用项目内的 `python -m fan_music import-midi`。
4. 导入结果替换当前项目，但可以用 `Ctrl+Z` 撤销。

MIDI 改编规则与命令行版本完全一致。

## 7. 使用提醒

- 风扇的音高来自叶片通过频率，不是普通扬声器。
- 电机有惯性，换速需要时间；短音符可能来不及达到目标音高。
- 多台电机同时发声会产生频谱遮蔽。程序显示风险，但不会擅自改谱。
- 软件中的转速、占空比、音域和 3.5τ 整定值都是仿真/编辑参数，不是电机额定值或安全值。实机可能因超速、飞车、轴承或叶片强度不足而损坏或伤人。
- 涉及真实电机、电源和驱动板时，必须确认供电、绝缘、限流、固定和散热措施。仿真结果不替代硬件手册或电气测量。

## 8. 常见问题

### 打开后提示找不到声部

确认文件包含 `[voice ...]` 声部，或使用旧式单电机格式。编辑器同时兼容 `[voice fan40]`、`[voice lead]` 和没有 header 的单电机谱。

### MIDI 导入失败

确认系统可运行 `python`，并确认 `fan_music` 目录在 `fan_studio.exe` 的上级目录中。

### 项目没有声音

先点击“渲染并播放”检查状态。若音符全部超出音域，检查器会显示红色提示。
